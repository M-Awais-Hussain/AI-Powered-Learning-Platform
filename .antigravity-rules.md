# AI Development Rules

## Code Reuse Policy
- Always analyze existing code first.
- Reuse available files and functions.
- Avoid creating new files unless required.

## Modification Policy
- Make minimal safe changes.
- Maintain project architecture.
- Follow existing naming conventions.

## Stability Policy
- Do not break existing features.
- Maintain backward compatibility.

## Output Policy
- Mention modified files.
- Mention reused logic.
